Docker Volumes
==============
- ollama-models                      # Persistent Ollama model storage

Quick Reference Commands
========================

Setup:
  cp .env.example .env
  # Edit .env with your API keys
  
Start:
  docker-compose up                  # Start and show logs
  docker-compose up -d              # Start in background
  ./start-docker.sh                 # Use convenience script
  make up                           # Use Makefile

Stop:
  docker-compose down               # Stop services
  make down                         # Stop with Make

Logs:
  docker-compose logs -f            # Follow all logs
  docker-compose logs -f chatpdf    # ChatPDF only
  make logs                         # Using Make

Models:
  docker exec -it chatpdf-ollama ollama pull llama3:8b
  make pull-models                  # Download common models

Access Points:
  http://localhost:8501             # Streamlit UI
  http://localhost:11434            # Ollama API
